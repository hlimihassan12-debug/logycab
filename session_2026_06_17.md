## Règles techniques rappelées

- SQL Server : `SELECT DISTINCT` + `ORDER BY` → la colonne de tri doit être dans le SELECT
- PHP + fetch JSON : lire l'action depuis `php://input` → `json_decode` → `$bodyJson['action']`
- Mapping JS : toujours inclure tous les champs utiles dans le `map()` (ne pas oublier `nb`)
- Réinitialisation mutuelle de champs : ne pas utiliser de variable de garde `if (champ === actif) return`
