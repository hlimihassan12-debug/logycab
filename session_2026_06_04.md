## 🔧 Principes techniques retenus

- `dispatchEvent` sur radios cachés = source de bugs boutons inertes → toujours appeler la fonction cible directement
- `required` HTML ne fonctionne pas avec AJAX → validation JS explicite obligatoire
- Code orphelin entre deux fonctions JS = tous les boutons inertes → vérifier systématiquement avec `grep -n "function "` après chaque modification
- Aperçu multi-lignes : `parties.join('\n')` dans le textarea readonly
