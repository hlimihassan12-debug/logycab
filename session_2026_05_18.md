## Règles importantes
- Toujours expliquer le code AVANT de demander une action
- Table jours fériés : T_JourFeries (sans s) — piège récurrent
- Format date SQL Server : YYYYMMDD (sans tirets) — universel
- Couleurs : #1a4a7a (bleu foncé), #2e6da4 (bleu), #27ae60 (vert), #e74c3c (rouge)
- RDV : toujours combiner `[DATE REDEZ VOUS]` ET `Date_Rdv` dans les requêtes
