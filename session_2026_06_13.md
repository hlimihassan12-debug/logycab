### 4. Sauvegarde des aperçus — nouveau_bilan_clinique.php
**Problème résolu :** les aperçus Examen et ECG n'étaient jamais sauvegardés en base.

**Causes identifiées et corrigées :**
- `readonly` sur les textareas `apercu_examen` et `apercu_ecg` bloquait `.value =` sous Chromium → remplacé par `pointer-events:none`
- Attribut `name` manquant → ajout de `name="CMLM_EXAMEN"` et `name="CMLM_ECG"`
- INSERT SQL `t_examen` : ajout colonne `CMLM_EXAMEN` + valeur `$_POST['CMLM_EXAMEN']`
- INSERT SQL `ecg` : ajout colonne `CMLM_ECG` + valeur `$_POST['CMLM_ECG']`
- JS `enregistrerAjax` : ajout du forçage `data.set('CMLM_EXAMEN')` et `data.set('CMLM_ECG')` (même pattern que `CMLM_ECHO`)

**Script SQL requis** (`setup_db_update.sql`) :
```sql
IF NOT EXISTS (SELECT 1 FROM sys.columns WHERE object_id = OBJECT_ID('t_examen') AND name = 'CMLM_EXAMEN')
    ALTER TABLE t_examen ADD CMLM_EXAMEN nvarchar(MAX) NULL;

IF NOT EXISTS (SELECT 1 FROM sys.columns WHERE object_id = OBJECT_ID('ecg') AND name = 'CMLM_ECG')
    ALTER TABLE ecg ADD CMLM_ECG nvarchar(MAX) NULL;
```
